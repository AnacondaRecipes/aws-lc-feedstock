# AWS‑LC Conda Recipe

Feedstock license: [BSD-3-Clause](https://github.com/AnacondaRecipes/aws-lc-feedstock/blob/main/LICENSE.txt)

Home: https://github.com/awslabs/aws-lc

Package license: Apache-2.0

This repository contains a conda recipe for building and packaging [AWS‑LC](https://github.com/aws/aws-lc), AWS’s fork of BoringSSL. AWS‑LC provides cryptographic primitives (such as `libcrypto.a`) used in various AWS components like s2n.
